# Taskset Maintainer Documentation

This section contains repository maintenance material for the Taskset delivery workspace. It stays separate from the primary human and agent guides while remaining available in the same Nextra documentation site.

## Contents

- `product/`: product direction and scope
- `architecture/`: system boundaries and accepted decisions
- `development/`: contribution, engineering, testing, and documentation
  workflows
- `technology.md`: preferred frontend, backend, language, and database choices

Contributors should start with the root `CONTRIBUTING.md`, then read the
relevant maintainer document before changing architecture, tooling, or
repository workflows.
